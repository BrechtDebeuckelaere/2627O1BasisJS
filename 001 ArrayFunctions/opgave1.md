# JavaScript Array Functions - Oefeningen

In deze documentatie vind je 5 eenvoudige opgaven om te oefenen met bekende JavaScript array methodes: `map`, `filter`, `find`, `reduce` en `forEach`.

---

## Opgave 1: Verdubbel de getallen (`map`)

Gegeven is de onderstaande array van getallen:

```javascript
const getallen = [2, 5, 8, 12];
```

**Opdracht:**  
Maak eenn nieuwe array waarin elk getal uit de oorspronkelijke array is vermenigvuldigd met 2.

**Verwachte uitkomst:**  
`[4, 10, 16, 24]`

---

## Opgave 2: Filter de onvoldoendes (`filter`)

Gegeven is een lijst met behaalde cijfers:

```javascript
const cijfers = [4, 7, 9, 3, 6, 5];
```

**Opdracht:**  
Maak een nieuwe array die alleen de voldoende cijfers bevat (5.5 of hoger).

**Verwachte uitkomst:**  
`[7, 9, 6]`

---

## Opgave 3: Zoek de eerste naam met een "A" (`find`)

Gegeven is de onderstaande array met namen:

```javascript
const namen = ["Tim", "Sanne", "Anouk", "Bram"];
```

**Opdracht:**  
Vind de eerste naam uit de array die begint met de letter **"A"**.

**Verwachte uitkomst:**  
`"Anouk"`

---

## Opgave 4: Bereken het totaal van de winkelmand (`reduce`)

Gegeven is een array met productprijzen:

```javascript
const prijzen = [10, 25, 5, 15];
```

**Opdracht:**  
Bereken de totale som van alle prijzen in de array.

**Verwachte uitkomst:**  
`55`

---

## Opgave 5: Print elk dier naar de console (`forEach`)

Gegeven is een array van dieren:

```javascript
const dieren = ["kat", "hond", "konijn"];
```

**Opdracht:**  
Print elk dier afzonderlijk in de console met de voorafgaande tekst: `"Dier: [naam]"`.

**Verwachte uitkomst:**

```text
Dier: kat
Dier: hond
Dier: konijn
```
